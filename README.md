# Artemis 32 — Cabinet de sages-femmes à Condom

Site vitrine du cabinet de sages-femmes Artemis 32 (Isabelle Baste Papelorey et Chloé Mac), 16 bis boulevard Saint-Jacques, 32100 Condom.

Le site tient dans un seul fichier : `index.html`.

## Mise en ligne avec GitHub Pages

Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.

## À compléter

- Liens Doctolib de chaque sage-femme : remplacer l'adresse des boutons `id="doctolib-isabelle"` et `id="doctolib-chloe"` dans `index.html`.
- Affiche Tecar : ajouter l'image dans le dépôt et la placer dans la section `id="tecar"`.
